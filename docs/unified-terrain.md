# Unified terrain constraint fit (experimental)
Run from repo root:
```powershell
py -m pip install -r requirements-elevation.txt
py -u src/unified_terrain.py
```
Uses local data/pilot.osm, output/elevation/ground.npy + ground.json and data/buildings/overture.geojson + manifest.json. Full local Overture snapshot required by default. Missing full snapshot: use fetch_buildings.py. Explicit --allow-partial with optional --benchmark PATH_TO_B01_ZIP permits partial trial. Overture checksum checked; coverage not independently verified. OSM multipolygon footprints/water supported; overlap with Overture >=.7 IoU and single significant match reuses OSM provisionally; other nearby Overture candidates held for review. Additional isolated candidates retained as unverified observations. OSM road, rail, water, bridge/tunnel and building passage buffers are approximate evidence; do not interpret as measured pavement widths. No external hydraulic or transport reference reconciliation yet.

## Fit
On the whole pilot shared 0.5m grid, subtract 50m Gaussian trend, protect connected residual regions >=.25m with a .5m seed and 4m2 area, local steep route samples, rail, mapped water and stacked/passage corridors. Unresolved footprints also retained for review. Taper residual toward Z0 over 8m. Group touching raster foundations; propose a constant median local relief (zero within .25m) unless overlapping protected relief, conflicting source observation, corridor or edge. Do not level blocked pads. Use weighted pad transitions over 3m with a guard near protected areas; no nearest-pad discontinuity assumption. Numerical assertions require exact planarity of proposed raster pad samples and unchanged protected residual. These are not native engine or continuous-interpolation validations. Retain source heights, no permanent changes. The shared region is still only the pilot; 200m edge review band reflects unbuffered Gaussian filter, not seam validation.

## Outputs
output/unified_terrain/terrain.npy (signed local candidate heightfield), constraint_status.npy (0 ordinary/transition, 1 protected, 2 proposed level pad, 3 blocked), edge_review.npy (independent edge flag), constraints.png and report.json (hashes, provenance, parameters, counts, pad bounds/conflicts). Not approved for compilation. Blocked pads must be resolved or excluded; don't treat nonzero residual as exact physical grade. Entrances, hardscape, hydraulic continuity, engineered routes, deck clearance, missing water sources, actual native/Viewpoint terrain import remain open. Full local Overture may greatly increase counts.
