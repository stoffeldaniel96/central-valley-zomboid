# Selective vertical sanitization
User decision 2026-11-26: for Central Valley geography, sanitize mechanically insignificant gradual regional slopes; prioritize abrupt depressions, hills, mounds, embankments and substantial changes over short distances. Preserve original absolute geodetic elevations and horizontal geometry. Ordinary terrain should generally compile to game Z0; signed local relief and independent decks/subsurface spaces remain. This supersedes a single fixed absolute elevation as the sole game zero mapping. Use a deterministic shared regional baseline field (not independently normalized tiles/benchmarks), preserve continuity across sector boundaries and apply the same local transform to related elevations; protect clearances, grades, drainage and topology. No final baseline or thresholds approved. Beyond Central Valley reconsider according to terrain.
