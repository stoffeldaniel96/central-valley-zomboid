# Terrain V2 conservative refinement
Run `py -u src/terrain_v2.py` after full V1 unified terrain. Reads and checksums the original DEM, OSM, V1 arrays and report; no source edits. Outputs output/unified_terrain_v2 with the same grid, separate constraint/status arrays and report. IDs refer to V1 pad records. All existing routes (approximate OSM buffers), edge band and V1 nonordinary samples immutable except explicitly released exact-matched relief-only pads. Candidate threshold 0.35m, 3/6/9m blending; reject increases in local forward-edge excess count, sum squared excess or maximum (tolerance 1e-5). Global smoothing of ordinary samples accepted only if corresponding edge scores improve or stay equal. Edge excess is absolute forward grade above max(8%, observed local residual grade); counts are not square counts. Centered-difference new-steep area compared on unchanged V1 eligible domain; expanded domain separately reported.
Actual full-pilot run: 2649 verified level groups vs 2644; five nonzero target pads released (467.25m2); 664 remain blocked. Immutable 10,628,080 samples unchanged. Forward-edge excess count 191061 -> 128942; squared excess 212.8701 -> 191.2740; max excess 1.00169 unchanged. Centered new-steep area 10153.75 -> 9988.75m2. Flat within 1cm 75.238 -> 75.044%. Among 422 relief-only groups 191 exceed change budget, 90 intersect route/edge, one unmatched, 135 fail transition test, five pass. Numerical conservative experiment only; no geographic approval. The high rejection rate indicates that V1's unclassified relief protection is too rigid for intended urban flattening. Next rebuild constraints with explicitly verified infrastructure as hard, unclassified DEM residuals as soft, ordinary foundations as planar constraints. Do not infer actual landforms from elevation alone. Need full footprint evidence, water and route/deck checks, native/Viewpoint interoperability. No source data committed.
