# ADR-002 — Elevation, chronology and interoperability
Adopted 2026-11-26. Continuous physical elevations and vertically overlapping structures are required; visual relief alone is insufficient. Modern 2026 geography, provisional pre-2008 institutional/commercial cutoff, 1993 dressing; outbreak date undecided. Prefer shared mod interfaces and native compatibility without sacrificing fidelity.

Research leads (not adopted dependencies):
- Project Viewpoint: https://steamcommunity.com/sharedfiles/filedetails/?id=3809306528
- Viewpoint Better Terrain: https://steamcommunity.com/sharedfiles/filedetails/?id=3815223174 — author describes physical terrain and collision changes targeting 42.21; local verification pending.
- Official next steps: https://projectzomboid.com/blog/news/2026/07/next-steps-2/ — announced additional optimization/modding support, not confirmation of native continuous elevation.
Evaluate actual APIs, licensing, exact game versions, save/network behavior and coexistence with other mods. Include alternative renderers; avoid choosing based on screenshots. Seek upstream collaboration before invasive changes. No runtime dependency or engine fork approved.
