Use --min-uses and --max-changes for sensitivity analysis. The report counts binary per-material coverage masks from 8x8 sample grids; unknown=unobserved, no texture assigned. Rotation equivalence applies to source geometry, not native sprite count or runtime rotation support. No bespoke per-square sprite.
