# Native slope vocabulary and asset generation: B01 offline experiment
Research: community property documentation https://github.com/PZ-Wiki-Modding/PZ-API-Docs/blob/main/docs/source/mapping/tile_properties.rst lists eight slope directions and 0..100 integer height limits. Community engine notes https://hydecogames.com/tools/mapformats/ document vanilla ramps in 5-point increments, custom slope support untested, floor pass vs solidfloor, depth textures and geometry metadata gate. 128x256 canvas and 192px/storey projection are provisional for our art; see https://github.com/cagatay-softgineer/pz-knox-architect and engine notes. Binary tdef layout documented in https://github.com/robotsmeller/pz-tilesheet. No external code copied. Need installed-version verification, not a guarantee of native behavior.

## Executed B01 actual terrain trial
Uses prior shared_ground.npz, 516x516 half-meter centers with 1m halo. Derive 257x257 shared corners; fit each tile to candidate eight-direction plane within one signed storey, rounding min/max to 1/5/10 percentage points. Search adjacent storeys. Experimental storey sqrt(6)m; direction interpreted uphill, not verified. Flat nonzero offsets included as geometry candidates, not verified native tiles. Independent fits are not a continuity solver.
- 1%: 1369 nonstandard geometry families, 367 >=10 uses, 15554 placements, 12426 in frequent families. P95 height error .0082787m, max .1357501m. Shared edge endpoint max disagreement .2082066m.
- 5%: 111 geometry families, 62 >=10 uses, 12234 placements, 12060 frequent. 265 material-specific families including unknown/conflict placeholder IDs, 113 >=10. P95 .0318681m, max .1348895m. 24960 mismatched shared edge endpoints (of 261120), 1031 >.1m, maximum .1837117m. 3689 negative base tiles. 1228 source tiles straddle storey boundaries (at any tested increment).
- 10%: 28 geometry families, 24 >=10 uses, 9578 placements, 9559 frequent. P95 .0613279m, max .1541213m. Shared edge endpoint max .244949m.
Error evaluated against 262144 V3 source half-meter samples, not original surveyed elevations. Independent fits create discontinuities; cannot ship this approximation as traversable terrain. Shared-corner constraints and storey transitions require actual engine experiments. Test flat offsets, diagonal slope direction/shape, signed levels, floor pass and vehicles/actors. Don't require Viewpoint or Better Terrain.
Generated separate downloadable experiment bundle: native_slope_lab.py, report, fitting arrays and 62 neutral reusable OBJ planes with corresponding color/depth previews in an eight-column atlas. Analytic projection (128x256, 192px/storey), provisional depth encoding. Not a native pack or tiledef, no final material art, no collision data, no Viewpoint-specific binding. Rare geometry not manufactured into assets. The executable experiment is delivered separately, not yet committed; no game art or proprietary mod code in repository.

## Local native contract
```powershell
py src/inspect_native_tiles.py --game-dir "C:\Program Files (x86)\Steam\steamapps\common\ProjectZomboid"
```
Read-only scanner of media/*.tiles and media/tile_definitions/*.tiles, hashes, merge patch properties, slope examples, floor material properties and B01 palette. Outputs output/native_tile_contract.json. Parser smoke test using a minimal byte-level fixture passed, actual game files not tested. Report parse errors and base duplicates; don't infer absence from partial scans. Lexical patch order provisional. No external runtime dependency.
